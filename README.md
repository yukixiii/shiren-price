# シレン値段識別

風来のシレン4・5・6・アスカ見参 の値段識別 Web アプリ。店の買値/売値から未識別アイテムの候補を特定します。

## 機能

- **値段識別**: 買値/売値と値段を入力すると候補アイテムを即時表示。祝福・呪い価格(倍率はタイトルごと。例: シレン6 ×2/×0.87、シレン5・4 ×1.1/×0.8、アスカ ×1.1/×0.9)や、杖などの回数による価格変動([n] 表示)にも対応
- **頻出価格チップ**: 現在の絞り込み条件で実在する価格をワンタップで選択
- **ダンジョン絞り込み**: ダンジョンを選ぶと、そのダンジョンに出現しないアイテムを候補から除外
- **識別済みチェック**: 識別できたアイテムを記録(ブラウザに保存)。候補表示でグレーアウト/非表示。「識別済み」タブから一覧確認と冒険リセット
- **値段表**: カテゴリ別の全アイテム価格一覧(逆引き)
- PC / スマホ両対応、ダークモード対応

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ユニットテスト (vitest)
npm run build    # 本番ビルド (dist/)
```

## デプロイ (GitHub Pages)

1. GitHub に `shiren-price` という名前でリポジトリを作成して push
   (リポジトリ名を変える場合は `vite.config.ts` の `base` を合わせる)
2. リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定
3. main ブランチへ push すると `.github/workflows/deploy.yml` が自動でビルド・公開

## タイトルの追加方法

ゲームデータは `src/data/*.json`(スキーマは `src/types.ts` の `GameData`)。

1. `src/data/<newgame>.json` を作成(カテゴリ・アイテム・祝福呪い倍率・ダンジョンをすべてデータで定義)
2. `src/data/index.ts` に import と `games` 配列への追加を1行ずつ追加(先頭がデフォルトのタイトル)

エンジン・UI はスキーマにのみ依存しているため、コード変更は不要です。

- 杖など回数で価格が変わるアイテムは `buyPerCharge` / `chargeMin` / `chargeMax` を設定
- ダンジョンの `itemPool` は出現アイテム名のリスト(包含方式、`items` の `name` と完全一致)

## データについて

アイテム価格・ダンジョン出現テーブルは攻略 wiki 等を参照して作成しています。
検証状況・出典・未検証項目は `src/data/NOTES.md` を参照してください。誤りを見つけた場合は JSON を直接修正してください。
