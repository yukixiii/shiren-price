## 検証できた点

- **売値率**: 「売値は買値の35%→小数点切り捨て」(seesaa明文)。miya・regamersの個別値とも一致。
- **祝福/呪い倍率**: 祝福=1.1倍、呪い・道具封印=0.8倍(seesaa明文)。miyaの3列表の実数値
  (例: 500/550/400、200/220/160)とも一致。**巷説の1.2/0.87は誤り(シレン5では1.1/0.8)**。
- **杖の回数単価**: 回数+1につき基本価格の5%上乗せ(seesaa明文+両wikiの実数表で確認)。
  買値増分は整数(基本600→30、900→45、1200→60、1500→75、1800→90)。
  売値増分は 基本売値×5% で端数あり(10.5等)→ 売値 = floor(基本売値 + 回数×増分)。
- **壺も容量で変動**: 容量+1につき5%上乗せ(杖と同じ)。hasCharges=true とし chargeは容量を表す。
  増分: 600→30 / 1000→50 / 1600→80 / 2000→100 / 2500→125 / 3500→175 / 6000→300 / 10000→500。
- **回数/容量の出現範囲**: seesaa値段一覧表の per-item 範囲を採用
  (例: 場所がえの杖5~7、鈍足・加速4~6、保存の壺3~5、強化の壺2~3、底抜け2~4、合成5固定)。
- **お香**: シレン5では独立カテゴリではなく「○○香の壺」(冷えびえ香・身かわし香・目配り香・山彦香、
  基本2500G)として壺カテゴリに存在 → pot に収録し incense カテゴリは作らない。
- **まがいもの(偽名)アイテム**(楽草、ドラコン草、合城の壺、身伐わりの杖、盛電の杖、召介状 等)は
  実在アイテムで正規品と同価格帯 → items に収録。原始に続く穴では18F以降出現、
  死線の回廊では出現しない(itemPoolに反映済み)。

## 未検証・推定の点

- **rounding**: "floor" とした。基本の35%切り捨ては確定だが、祝福/呪い適用時の端数処理は
  ほぼfloorで整合するもののmiyaの一部端数ケース(薬草の祝福売値18・呪い売値14)は
  「floor(売値×倍率)」とも「floor(買値×倍率×0.35)」とも完全には一致せず、
  ゲーム内部の計算順序は未検証。実害は売値17.5のような端数ティアのみ(±1G)。
- **札の価格**: 全13種600G/210Gはseesaaのみで確認(miyaに札表がない)。単一ソースだが
  seesaa上で全札同一価格と明記。値段識別上は札同士を価格で区別できない。
- **フィーバーの壺=容量3固定、乙女の祈りの壺・天上の器の容量表記「-」**: seesaaの表記に従い
  乙女の祈り・天上の器は chargeMin=chargeMax=3(miyaの容量3行に掲載)として推定。
- **itemPool の抽出**: 各ダンジョンページの「入手可能アイテム」節のテキストから
  アイテム名の完全一致検索で抽出。床落ち/店売り/変化の壺限定/トド限定の区別はしていない
  (入手経路を問わず出現し得るものを全収録)。
- **底抜けの壺の範囲2~4、強イヒの壺3~5** などまがいもの・低頻度品の容量範囲はseesaa太字表の
  読み取りで、実測検証はしていない。

## 表記ゆれメモ

- 「水がめ」(「水がめの壺」ではない)、「四二鉢」「天上の器」は壺カテゴリだが名称に「壺」を含まない。
- 「紹介状」「召介状」「ただの紙切れ」「ぬれた巻物」は巻物カテゴリだが名称に「巻物」を含まない。
- 偽物ペアの字面: 薬草/楽草、復活/腹活、やりなおし/やりなおせ、ドラゴン/ドラコン、めぐすり/ぬぐすり、
  困った時/国った時、地の恵み/他の恵み、天の恵み/夫の恵み、タグ/タダ、壺増大/壺増犬、紹介状/召介状、
  技回復/枝回復、識別要注意: 透視/透ネ見、気配察知/気配察血、道具感知/道具感血、
  身代わり/身伐わり、かなしばり/かなしばい、転ばぬ先/転ばぬ先生、感電/盛電、
  合成/合城、強化/強イヒ、変化/変花。
- 迷いの井戸は持ち込み可、二撃の道・ゲンさんのシマ・人生の落し穴はアイテム識別済み、
  おにぎり穴は未識別(腕輪・草・杖・壺)だがwikiに機械可読な出現テーブルがないため不採用。
