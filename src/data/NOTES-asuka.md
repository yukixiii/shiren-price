# asuka.json 調査メモ

対象は Windows 版「風来のシレン外伝 女剣士アスカ見参！ for Windows」(裏白蛇島などクリア後ダンジョンを含む)。

## 最重要: 出典 Wiki の「売値」「買値」は本アプリと逆

アスカ攻略 Wiki (asuka.lsx3.com) の価格表は **店側の視点** で書かれている。

- Wiki の「売値」= 店がプレイヤーに売る価格 = 本アプリの `buy`(買値)
- Wiki の「買値」= 店がプレイヤーから買い取る価格 = 本アプリの `sell`(売値)

例: 識別の巻物 Wiki「売値500/買値250」→ `buy: 500, sell: 250`。
第2ソース(下記 nusutto)は通常の買値/売値表記で、全アイテムの数値が一致することを確認済み。

## 検証できた点

- **売値率**: 原則 売値 = 買値×0.5 だが例外多数(気力の腕輪 25000/1000、識別の腕輪 25000/12000、
  ワナ師の腕輪 25000/10000、まもりの腕輪 7500/3000、身がわりの腕輪 7500/3000、聖域の巻物 7500/2500、
  ねだやしの巻物 25000/400、ちからの種・毒草 1500/700、封印の杖 2000/500、鈍足の杖 1200/400、祝福の壺 5000/2000 等)。
  そのため計算ではなく表の値を個別収録。
- **祝福/呪い倍率**: 「呪いで1割減、祝福で1割増」(値段一覧表明文)→ `{blessed: 1.1, cursed: 0.9}`。
- **杖の回数単価**: 品目ごとに異なる(基本値の5%とは限らない)。
  ふきとばし 500+25 / イカリ系 800+40 / 回復 800+80 / 転ばぬ先 1000+50 / 鈍足・一時しのぎ・かなしばり 1200+60 /
  封印・いかずち系 2000+100 / 倍速 2000+200 / オオイカリ系 2500+125 / しあわせ 3000+150 / 不幸 3000+300。
  売値側の増分も品目ごと(鈍足 400+20 だが 一時しのぎ 600+30 等)。表の 0〜7 の全列が floor(基本+増分×n) と一致。
  Wiki 記載の識別例(1120・1200・1280・1360G→回復の杖、2800・3200・3400G→倍速の杖、4200G以上→不幸の杖)と整合。
- **壺の容量単価**: 同様に品目ごと(回復 1000+50 / 保存 1200+60 / 識別 1500+75 / やりすごし 2000+100 /
  倉庫 3000+150 / 合成 4000+200 / 祝福 5000+250 / 強化 15000+750)。売値増分 37.5 等の端数は合計切り捨て(787 等)で表と一致。
- **回数/容量の出現範囲**: 杖 3〜7(転ばぬ先の杖は 0 固定)、壺 3〜6(合成の壺は 2〜4)。
- **収録範囲**: 草・種26 / 巻物35 / 杖25 / 腕輪30 / 壺14 = 130種。

## 未検証・推定の点

- **rounding**: 呪い(×0.9)・祝福(×1.1)適用後の端数処理は Wiki に記載なし → floor を仮定。
  影響するのは 25/75 など奇数系の基本値(例: 雑草 25×0.9=22.5)のみ。
- **店売り品の回数範囲**: 床落ちの範囲(杖3〜7・壺3〜6)をそのまま店売りにも適用。
- **itemPool**: 出現率が全列 "-" のアイテムを除外し、それ以外(床/店/専門店のいずれかで出現率あり)を全収録。
  入手経路は区別しない。

## 表記ゆれメモ

- 出現アイテムページでは「身代わりの腕輪」、値段一覧表では「身がわりの腕輪」→ 本データは「身がわりの腕輪」に統一。
- nusutto 側の表記: 困ったときの巻物(本データ: 困った時の巻物)、奥義の巻物(本データ: 奥技の巻物)、高飛び草(本データ: 高とび草)。
- 「水がめ」は壺カテゴリだが名称に「壺」を含まない。
