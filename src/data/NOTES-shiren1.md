# shiren1.json (初代シレン SFC版) 調査メモ

作成日: 2026-09-05

  - アイテム一覧(全カテゴリの買値/売値、杖・壺の回数別価格表、ダンジョン別出現列): https://seesaawiki.jp/shiren1/d/%A5%A2%A5%A4%A5%C6%A5%E0
  - 価格での識別(フェイの最終問題向けの価格→候補一覧。杖・壺の回数別価格を明記): https://seesaawiki.jp/shiren1/d/%B2%C1%B3%CA%A4%C7%A4%CE%BC%B1%CA%CC
  - 呪い(「呪いはアイテムの値段に影響しない」の明記): https://seesaawiki.jp/shiren1/d/%BC%F6%A4%A4
  - 各アイテム個別ページ(あかりの巻物・拾えずの巻物・真空斬りの巻物・メッキの巻物・ブフーの杖・ガイコツまどうの杖など、表の rowspan で読み取りにくい行の確認用)
  - フェイの最終問題 / 掛軸裏の洞窟 / 食神のほこら / こばみ谷 の各ページ
- **SFCシレンアイテムデータ** (shurefushidan.nusutto.jp/SFCitem.html、Shift_JIS) — 照合用。壺の店価格表(容量3〜5)あり。
- 注意: Re:Gamers の「SFC/DS/スマホ 値段早見表」は DS/アプリ版の価格(混乱草800、天使の種5000、吸い出し1000 など SFC と異なる)のため **不採用**。

## 検証できた点

- **祝福は存在しない。呪いは価格に影響しない**(wiki「呪い」ページ)。呪われた武器・盾が安いのは -1 修正値分が引かれているため。
  → `priceModifiers: { blessed: 1, cursed: 1 }`。エンジン側は倍率1の状態を候補から除外する。
- **杖・壺の計算式**: `基本価格 + 基本価格 × 回数(容量) / 10`(wiki「アイテム」に明記。回数0の価格が基本価格)。売値も同じ式で、売値基本は原則買値の半額。
  - 杖: ガイコツまどう 300/150、しあわせ・不幸・ふきとばし・一時しのぎ 500/250、場所替え 700/350、かなしばり・身がわり・痛み分け・封印 1000/500、ブフー 2000/500(売値基本は個別ページで 500(+50) を確認。買値の半額ではない)。
  - 壺: 弱化 1000/200、識別・変化 1000/500、倉庫 2500/1200、分裂・合成・うっぷんばらし・アホくさい・割れない・ガイバラ の売値基本 1500、強化 10000/5000、背中 1500/700、トド 1600/600、魔物のるつぼ 2000/300。
  - **容量で値段が変わらない壺** = やりすごし 1000/400、保存 1600/600、底抜け 2500/400(wiki明記)。`buyPerCharge/sellPerCharge: 0` で収録し、回数候補を出さない。
- **杖の回数**: 入手時 5〜7。封印の杖のみ 8 もある(wiki「価格での識別」: 買値1800の杖は封印の杖[8]で確定)。
- **売値が半額でない品**: 超不幸の種 200/30、不幸の種 200/40、くねくね草 200/50、胃縮小の種 200/60、キグニ族の種 200/100、無敵草 3000/100、天使の種 10000/1500、自爆・パワーアップの巻物(売100)、困った時の巻物 1000/250、あかりの巻物 300/250、拾えずの巻物 300/300(唯一買値=売値)、メッキの巻物 1500/500、ジェノサイドの巻物 50000/750、識別の腕輪以外の腕輪は全て半額。
- **未識別の範囲**: フェイの最終問題のみ草・巻物を含む全アイテムが未識別。こばみ谷(テーブルマウンテン)・掛軸裏の洞窟・食神のほこらでは未識別なのは腕輪・杖・壺のみ(wiki フェイの最終問題ページ「腕輪、杖、壺だけでなく草、巻物までを含めたアイテム全てが未識別」)。
- **itemPool**: wiki「アイテム」表のダンジョン別出現列(テ/掛/食/ﾌｪ)で ○/店/拾/モ のものを採用、×/− を除外。雑草・どく草・混乱草・睡眠草はモンスター由来で識別済み入手のため全ダンジョンの pool から除外(items には収録)。
- 武器・盾・矢・食料は名前が識別済みのため収録しない(修正値による価格差は本アプリの対象外)。聖域の巻物・全滅の巻物は価格なし(白紙に書く専用)のため未収録。

## 未検証・推定の点

- **壺の容量範囲**: wiki「価格での識別」は 3〜6 の価格を列挙、shurefushidan の店価格表は 3〜5。**3〜6 で収録**(候補が1つ増える側で取りこぼしはない)。
- **店売り時の杖の回数範囲**が床落ちと同じ(5〜7)かは未検証。
- **ガイコツまどうの杖**はモンスタードロップ限定。ドロップ時に未識別かは未確認だが pool に含めている。
- **rounding**: 全価格が整数演算で端数が出ないため floor/round/ceil の区別は効かない。"floor" を採用。
- テーブルマウンテン等での「草・巻物は識別済み」は wiki の記述に基づく推定。

## 表記ゆれメモ

- 「値切の腕輪」: wiki アイテム一覧の表記を採用(「価格での識別」ページや他サイトでは「値切りの腕輪」)。
- 「1ツ目殺し」「こわれないつるはし」など武器名は未収録。
- 「アホくさい壺」「魔物のるつぼ」は名称に「の壺」を含まない。
- 「ワナの巻物」「ワナ師の腕輪」はカタカナ表記(wiki準拠)。
