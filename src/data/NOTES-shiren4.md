# shiren4.json 調査メモ

対象は PSP 版「風来のシレン4 plus」(DS 版「神の眼と悪魔のヘソ」を含む)。価格表は両版共通。

## 使用ソース

- 不思議のダンジョン 風来のシレン4 神の眼と悪魔のヘソ Wiki (seesaawiki) 値段一覧表
  https://seesaawiki.jp/shiren_4/d/%C3%CD%C3%CA%B0%EC%CD%F7%C9%BD
  (価格の主ソース。巻物/草・種/腕輪/札/壺/杖の全表、倍率・増分・端数処理の明文記載あり。
   武器・盾の表もあるが本アプリでは未収録)
- 同 Wiki 杖ページ https://seesaawiki.jp/shiren_4/d/%BE%F3 (「拾最小/拾最大」列 → chargeMin/Max)
- 同 Wiki 壺ページ https://seesaawiki.jp/shiren_4/d/%D4%E4 (「拾い最小数/最大数」列 → chargeMin/Max)
- 同 Wiki アイテム出現場所 https://seesaawiki.jp/shiren_4/d/%A5%A2%A5%A4%A5%C6%A5%E0%BD%D0%B8%BD%BE%EC%BD%EA
  (15ダンジョン × 全アイテムの出現表 → itemPool)
- 同 Wiki 各ダンジョンページ(浜辺の魔洞 / シレンへの道 / 修羅の道 / 不思議の商店街 / 置けずの洞窟 /
  夢中の小道 / エメラルドテラス / プラチナ・パラダイス / ジャガーの狩りの森 ほか)の
  「識別」行(カテゴリごとの 未識別/識別済/登場しない) → 収録ダンジョンの選定

取得は HTML の table をセル単位でパース(rowspan 展開)。テキスト化すると4列並置表の列が崩れるため。

## 検証できた点

- **売値率**: 全アイテムで 売値 = 買値×0.35 切り捨て(表の値をそのまま収録)。
- **祝福/封印倍率**: 値段一覧表に「祝福状態は買値・売値ともに1.1倍」「封印状態は0.8倍」と明文。
  → `priceModifiers: {blessed: 1.1, cursed: 0.8}`。シレン5plus と同一。
- **回数/容量単価**: 「修正値、壺の容量、杖の回数が+1につき基本値×0.05を+する。増量合計の小数点以下は切り捨て」
  (明文+表の実数値で全行検証: 買値・売値とも floor(基本 + 増分×n) が表と一致)。
  例: 識別の壺[4] = 600 + 30×4 = 720(Wiki 記載例と一致)。
- **回数/容量の出現範囲**: 杖ページ・壺ページの per-item 範囲を採用。
  杖は 5〜7(場所がえ・吹き飛ばし・飛びつき・魔道・痛み分け・転ばぬ先・ワナ消し・ただの杖)か
  4〜6(それ以外)。壺は 3〜5(保存・識別 等)/ 2〜3(おはらい・たたり・祝福・強化・弱化)/ 2〜4(蔵・底抜け)。
- **収録範囲**: 草・種29 / 巻物37 / 杖19 / 腕輪25 / 壺24 / 札11 = 145種。値段一覧表の全行を収録。

## 未検証・推定の点

- **「呪い」状態の倍率**: Wiki の値段一覧表が明記しているのは祝福(×1.1)と封印(×0.8)のみで、
  呪い状態の価格は記載がない。シレン5plus(呪い・封印とも×0.8)に倣い cursed=0.8 として扱っている。
- **rounding**: 増分の端数処理は「合計を切り捨て」と明文だが、祝福/封印倍率をかけた後の端数処理は明記なし。
  floor を仮定(シレン5と同じ)。
- **出現表の空欄**: アイテム出現場所の表で「空欄=未確認」のセルは、候補から漏れる害の方が大きいと判断し
  itemPool に **含めている**(×・− のみ除外)。空欄が多いのはシレンへの道(34)・不思議の商店街(44)・
  置けずの洞窟(27)・修羅の道(21)・ジャガーの狩りの森(壺19)。浜辺の魔洞・夢中の小道は空欄なし。
- **itemPool の入手経路**: 床落ち/店/高級店/変化の壺/壁の中/クリア報酬 を区別せず全収録(既存タイトルと同方針)。
- DS 版と PSP 版で一部アイテムの出現有無が異なる(出現場所ページのコメント参照)が、表は区別していない。

## 表記ゆれメモ

- 「幸せの杖」(値段一覧表・杖ページ)と「しあわせの杖」(アイテム出現場所)が混在 → 本データは「しあわせの杖」
  (しあわせ草・しあわせの腕輪と同じひらがな表記)に統一。
- 「四二鉢」(値段一覧表・出現場所)と「四ニ鉢」(壺ページ、カタカナのニ)が混在 → 「四二鉢」に統一。
- 出現表の「〇」(U+3007)と「○」(U+25CB)はどちらも出現扱い。
- 「紹介状」「ぬれた巻物」「ただの紙切れ」は巻物カテゴリ、「四二鉢」「水がめ」「油壺」は壺カテゴリ(名称に「壺」を含まないものあり)。
